# Obleas Dulce Encanto

Proyecto web completo de una tienda ficticia de obleas.

## Archivos
- index.html: estructura de la página.
- style.css: diseño responsive.
- script.js: menú, personalizador, carrito, localStorage, formulario y pedido por WhatsApp.

## Cómo usarlo
1. Descomprime la carpeta.
2. Abre `index.html` en Chrome, Edge o Firefox.
3. Para publicar el sitio, sube los tres archivos a tu hosting.

## Datos que debes cambiar
En `index.html` cambia:
- número de WhatsApp
- ubicación
- horario
- nombre del negocio si quieres otro.

En `script.js` puedes cambiar productos, descripciones y precios.

Nota: los emojis funcionan como imágenes provisionales para que el proyecto sea totalmente funcional sin depender de archivos de imágenes externos.
